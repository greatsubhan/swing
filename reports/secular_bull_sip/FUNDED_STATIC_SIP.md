# Secular Bull SIP Under Static Funded Rules

## Funded Rules Applied

- Starting equity: `$100,000`
- Static daily floor: `$95,000`
- Static overall floor: `$90,000`
- Monthly SIP entries still occur on the first trading day of each month.
- New position size is automatically reduced with a `size multiplier` so the account survives the funded floors.
- This is a funded-account simulation, not an external-capital contribution model.

## Read

- `Size Mult` is the largest fraction of the lecture-style monthly position size that survived the funded floors over the full sample.
- `Eff. Monthly Notional` is `account/12 * leverage * size multiplier`.
- Higher net PnL is not enough on its own; if the safe size collapses too far, the asset is less practical for a funded SIP lane.
- This pass is the prop-style risk layer only. It still does not add correction-entry timing.
